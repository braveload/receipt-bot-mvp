코드를 작성하기 전에 다음 순서로 판단합니다.

1. 이 기능이 필요한가? 필요하지 않으면 YAGNI 원칙에 따라 생략합니다.
2. Python 표준 라이브러리로 가능한가? 가능하면 표준 라이브러리를 사용합니다.
3. FastAPI, 카카오 오픈빌더, Render, SQLite 등 플랫폼 기본 기능이 있는가? 있으면 이를 사용합니다.
4. 이미 설치된 의존성으로 가능한가? 가능하면 기존 의존성을 재사용합니다.
5. 읽기 쉽고 테스트 가능한 한 줄 구현으로 충분한가? 충분하면 한 줄로 구현합니다.
6. 위 방법으로 해결되지 않을 때만 최소 기능 코드를 작성합니다.

짧은 코드가 보안, 검증, 가독성, 테스트보다 우선하지는 않습니다. 웹훅 인증, 만료 서명 링크,
개인정보 처리처럼 위험도가 있는 코드는 명시적으로 구현하고 자동화 테스트로 검증합니다.

- SQLite 저장: Python `sqlite3` 유지
- 만료 링크: `hmac`, `hashlib`, `datetime` 기반 구현 유지
- 이미지 수집: 카카오의 `@sys.plugin.secureimage` 사용
- HTTP 호출: 기존 `httpx` 재사용
- 엑셀 생성: 기존 `openpyxl` 재사용
- 환경변수 로딩: 기존 `python-dotenv` 재사용
