# 영수증봇 운영 및 삭제 정책

기준일: 2026-07-24

## 운영 저장소

- 운영 데이터: Neon PostgreSQL
- 로컬 개발·자동 테스트: SQLite
- 원본 영수증 이미지: 공개 URL을 남기지 않고 운영 DB의 비공개 BLOB으로 저장
- 이미지 중복 검사: 사용자별 SHA-256 해시 비교

## 사용자 삭제 흐름

1. 사용자가 `삭제`를 입력한다.
2. 봇이 가장 최근에 저장한 영수증을 보여주고 영구 삭제 여부를 묻는다.
3. 사용자가 `삭제확정`을 입력해야 데이터와 원본 이미지가 함께 삭제된다.
4. 다른 사용자의 데이터에는 영향을 주지 않는다.

삭제한 운영 데이터는 앱에서 복구하지 않는다. 별도로 생성한 암호화·접근통제 백업이
있다면 최대 30일 안에 폐기한다. 현재 저장소의 수동 백업 파일은 Drive에 업로드하지 않는다.

## 운영 점검

- `/health`가 HTTP 200과 `{"status":"ok"}`를 반환하는지 확인한다.
- Render 환경변수에 `DATABASE_URL`, `GOOGLE_VISION_API_KEY`,
  `REPORT_SIGNING_SECRET`, `PUBLIC_BASE_URL`, `STORE_RECEIPT_IMAGES=true`가
  설정되어 있는지 확인한다.
- `.env`, DB 파일, 백업, API 키, 사용자 영수증 이미지는 GitHub·Drive에 올리지 않는다.
