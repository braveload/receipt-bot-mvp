# 리로웍스 홈페이지 배포 직전 체크리스트

## 현재 완료된 항목

- FastAPI가 회사 홈페이지, 개인정보처리방침, 서비스 이용 안내와 정적 자산을 함께 제공
- 홈페이지 문의를 SQLite 또는 PostgreSQL에 먼저 저장
- 네이버 SMTP 알림 실패 시에도 문의 데이터 보존
- 문의 입력 검증, 허니팟, 시간당 반복 전송 제한, 원본 IP 미저장
- 공식 로고, 파비콘, Open Graph 공유 이미지, canonical URL, 구조화 데이터
- `robots.txt`, `sitemap.xml`, `/health`
- 사업자 등록 전 상태에 맞춘 푸터와 법적 안내

## Render에서 배포 직전에 직접 입력할 값

- `GOOGLE_VISION_API_KEY`
- `DATABASE_URL`
- `SMTP_USERNAME`: 네이버 메일 주소 또는 SMTP 로그인 아이디
- `SMTP_PASSWORD`: 네이버 SMTP용 앱 비밀번호
- `PUBLIC_BASE_URL`: 실제 Render 또는 연결한 도메인의 HTTPS 주소

비밀값은 채팅, 코드, Git 커밋에 입력하지 않고 Render의 Environment에만 저장합니다.

## 배포 직전 확인

1. 네이버 메일 환경설정에서 SMTP 사용을 허용하고 앱 비밀번호를 준비합니다.
2. Render Environment에 위 값을 입력합니다.
3. `WEBHOOK_SECRET`을 사용할 경우 카카오 오픈빌더가 동일 헤더를 전달하는지 확인합니다.
4. 사업자등록이 완료되면 상호, 사업자등록번호, 사업장 주소를 푸터와 정책 문서에 추가합니다.
5. 홈페이지 공개 후 `/`, `/health`, `/robots.txt`, `/sitemap.xml`을 확인합니다.
6. 실제 문의 1건을 접수해 DB 저장과 `reromoon@naver.com` 알림을 확인합니다.
7. 실제 카카오톡 영수증 접수와 서명된 엑셀 보고서 다운로드를 확인합니다.

## 이번 작업에서 실행하지 않는 항목

- Render 실제 배포 버튼 실행
- 도메인 구매 또는 DNS 변경
- 카카오 챗봇 재배포
- 네이버 계정 또는 앱 비밀번호 입력
