## 확정 범위

- 초기 고객은 1인 사업자로 둔다.
- MVP는 카카오톡의 보안 이미지 전송을 통한 영수증 사진 등록에 집중한다.
- 카드 문자와 카드사 앱 알림 자동수집은 실제 수요 확인 전까지 보류한다.
- OCR 결과는 자동 확정하지 않고 `결과 확인 → 수정 → 저장` 단계를 거친다.
